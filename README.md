## About

This is the source code for my personal portfolio website. It showcases my experience, skills, and projects in B2B marketing, brand strategy, and AI-integrated creative workflows across the EMEA region.

## Features

- Responsive single-page design (works on mobile & desktop)
- Animated hero section with background grid
- About section with key stats
- Skills grid with proficiency indicators
- Career timeline
- Projects & achievements showcase
- Contact section

## Tech Stack

- Pure HTML & CSS — no frameworks, no dependencies
- Google Fonts (Syne + Manrope)
- Zero JavaScript required

## How to Run Locally

Just open `index.html` in any browser — no setup needed.

```bash
# Clone the repo
git clone https://github.com/yourusername/yourusername.github.io.git

# Open in browser
open index.html
```
